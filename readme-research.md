# README research and editorial decisions

Last updated: 2026-10-22

Reviewed current primary sources to improve the personal profile. This is a set
of useful examples, not a ranking of contributors. Thirteen READMEs and one
additional contributor profile were inspected.

## Sources and useful patterns

| Source | Pattern worth adapting |
| --- | --- |
| [Peter Steinberger](https://github.com/steipete/steipete/blob/main/README.md) | A selected starting list before a larger catalogue; descriptions explain what software enables. |
| [Anthony Fu](https://github.com/antfu/antfu/blob/main/README.md) | Compact navigation gives each destination a clear role. |
| [Sindre Sorhus](https://github.com/sindresorhus/sindresorhus/blob/main/readme.md) | Personal voice and prominent destinations for current work. |
| [Simon Willison](https://github.com/simonw/simonw/blob/main/README.md) | Principal projects first, followed by concrete artifacts and links to fuller collections. |
| [Sebastián Ramírez](https://github.com/tiangolo/tiangolo/blob/main/README.md) | Named creations and current work establish identity; a short background adds context. |
| [Evan You's profile](https://github.com/yyx990803) | A compact founder/author identity and selected pinned projects. This is a profile example: no public profile README was found. |

## Applied to this profile

- Replaced the generic role list with a concrete explanation of the work.
- Made the four featured projects answer reader tasks: build interfaces,
  evaluate changes, carry context, and reuse workflows.
- Added a verified next destination for each featured project: demos, local
  quick start, specification, or installation guide.
- Kept the existing real agentcn-ui demo screenshot and described what it shows.
- Grouped standalone apps separately from infrastructure, retaining their setup
  caveat and source links.
- Removed the two duplicate expandable catalogues and repeated philosophy
  paragraph. The complete [project index](projects.md) owns breadth, maturity,
  team attribution, and fork provenance.
- Preserved the aerospace background, current work, concise stack, and Madrid
  community projects as personal context.

No third-party copy, logos, screenshots, badges, follower counts, or traction
claims were imported. The examples inform information hierarchy and navigation;
the profile describes Álvaro's own work. Existing optional metrics tooling stays
preserved and inactive as documented in [scripts/README.md](scripts/README.md).
