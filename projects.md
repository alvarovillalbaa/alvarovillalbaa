# Project index

Last updated: 2026-10-22

The [profile README](README.md) highlights where to start. This index covers every
public project repository in my personal GitHub account at the review date:
**28 projects**, plus **8 upstream forks** attributed below. The profile repository
itself is excluded. Private repositories and organization-owned code are outside
this public index; Clous and Sentyl are introduced in the profile.

Descriptions follow project documentation and source, with prototypes and team
contributions identified. An app or demo link is an entry point, not a claim that
every integration has been verified.

## Agent infrastructure & developer tools

| Project | Purpose and current scope |
| --- | --- |
| [agentcn-ui](https://github.com/alvarovillalbaa/agentcn-ui) | React components for agent runs, tool calls, approvals, memory, artifacts, and evaluation. Consumers supply execution, authorization, and persistence. [Docs & demos](https://agentcn-ui.vercel.app/). |
| [open-evals](https://github.com/alvarovillalbaa/open-evals) | Provider-independent AI evaluations and system-prompt optimization, with reproducible runs and release gates. Deterministic evals run locally without AI credentials; hosted auth and optional optimizer engines need configuration. |
| [AFS](https://github.com/alvarovillalbaa/afs) | A portable filesystem and Markdown specification for agent context, durable knowledge, and provenance, with scaffolding, validation, and migration tools. |
| [Agent Company / plugins](https://github.com/alvarovillalbaa/plugins) | Reusable skills, commands, rules, and agents across engineering, product, and business operations, with a runtime-neutral installer. |
| [Sonant](https://github.com/alvarovillalbaa/sonant) | Sound feedback for React and the web, with editable recipes, playback controls, an npm library, and a copy-in CLI. [Playground](https://sonant-beta.vercel.app/). |
| [Search Gateway](https://github.com/alvarovillalbaa/search-gateway) | One API for multi-provider AI search and source retrieval, TypeScript/Python SDKs, and MCP tools. GitHub release artifacts are available; live vendor behavior remains unverified. |
| [OCR Gateway](https://github.com/alvarovillalbaa/ocr-gateway) | Self-hosted document parsing across OCR, vision, and local providers, with source citations and embedding-ready chunks. GitHub release artifacts are available; live provider accuracy remains unverified. |
| [MCPCN](https://github.com/alvarovillalbaa/mcpcn-ui) | Schema-first React components and an MCP Apps runtime for human-controlled agent workflows. Public package and hosted demo availability have not been verified. |
| [AI App Jumpstart](https://github.com/alvarovillalbaa/ai-app-jumpstart) | An evolving Next.js/Eve starter sharing application data across browser, REST, CLI, and MCP. Hosted acceptance is pending. |
